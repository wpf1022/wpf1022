### [紫禁城 · 中轴](https://wpf1022.github.io/forbidden-city-3d/) 　·　[源码](https://github.com/wpf1022/forbidden-city-3d)

用 **Three.js** 在浏览器里重建故宫中轴线：太和殿、中和殿、保和殿、太和门、金水桥、午门。

**没有一个外部模型，没有一张贴图。** 屋顶曲面由参数化高度场实时生成，全部纹理由 Canvas 2D 运行时绘制，源码仅 60 KB。

几处值得说的实现：

- **庑殿顶与攒尖顶用同一个高度场函数表达** —— 令正脊半长 `r = 0`，函数自动退化为四角攒尖，中和殿直接复用
- **四角起翘**用 `t⁸ · min(tx, tz)` 叠加：`t⁸` 限定只在檐口附近生效，`min(tx, tz)` 保证只在角点生效，边中点处恒为 0
- **天空渐变经 `PMREMGenerator` 转为环境反射贴图** —— 否则 `metalness` 较高的琉璃瓦和水面会渲染成纯黑

`Three.js` · `WebGL` · `参数化几何` · `程序化纹理` · `MIT`
